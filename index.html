两种用法 Two ways to use

① 在线版（本页「进入应用」）：单文件 HTML，浏览器直接打开即用，可勾选另存命中文件。
② Windows 桌面版（下载 exe）：带原生文件夹选择器、最近目录记忆、「打开所在目录」定位、导出摘录——功能最全。
Online version: single-file HTML, runs in any browser. Desktop exe: native folder picker, recent folders, reveal-in-Explorer, export excerpts.

隐私与安全 Privacy & Safety

本工具不联网、不上传、不统计任何文件内容：桌面版的服务只绑定 127.0.0.1 本机回环，扫描与搜索全部在本地完成；在线版同样只在你自己的浏览器里运行。无账号、无遥测。
No network, no upload, no telemetry. The desktop server binds to 127.0.0.1 loopback only; all scanning happens locally. The online version runs entirely in your own browser.
